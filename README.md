# Deep Roots Family Chiropractic (design preview)

This repository is a noindex GitHub Pages design preview of a student pre-opening landing page for Deep Roots Family Chiropractic (Fort Wayne, IN). It is not the live site.

- Preview URL: https://localember.github.io/deep-roots-family-chiro-preview/
- Do not attach a custom domain or CNAME. Do not point deeprootsfamilychiro.com at this preview.
- Every page is `noindex, nofollow`. Forms on this preview do not submit or send data.

Modeled on the live Voeller Family Chiropractic and Rajoo Family Chiropractic student landings, with Deep Roots facts, copy, and brand applied.
